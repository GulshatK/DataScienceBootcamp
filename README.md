# DataScienceBootcamp
Решение: Кандидатогенерация
Подход: Нейросетевые эмбеддинги (Sentence Transformers) и косинусное сходство

Этапы:
1. Чтение файлов, заполнение пропусков, объединение текстовых признаков запросов и объявлений в общие строки
2. Обрезка текстов до 128 символов для ускорения работы модели
3. Векторизация: генерация эмбеддингов с помощью модели intfloat/multilingual-e5-small
4. Расчет косинусного сходства батчами по 200 запросов
5. Выбор 50 item для каждого запроса, сохранение в answer.csv

Используемые библиотеки:
- pandas
- numpy
- sentence-transformers
- torch
