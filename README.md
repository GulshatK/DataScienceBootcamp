# DataScienceBootcamp
Решение: Кандидатогенерация
Подход: TF-IDF и косинусное сходство

Этапы:
1. Чтение файлов, заполнение пропусков, объединение текстовых признаков запросов и объявлений в общие строки
2. Векторизация: TF-IDF
3. Расчет сходства батчами по 200 запросов
4. Выбор 50 item для каждого запроса, сохранение в answer.csv

Используемые библиотеки:
- pandas
- numpy
- scikit-learn
