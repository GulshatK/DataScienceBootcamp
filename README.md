# DataScienceBootcamp
Решение: Кандидатогенерация

## Данные и признаки
Взяла файлы queries и items, соединила тексты запроса (search_query, параметры) и объявления (заголовок, описание, параметры) в одну строку. Числа (цена, рейтинг) не трогала, так как искала по смыслу текста.

## Модели и алгоритмы
1. Сначала попробовала TF-IDF (Recall@50 = 0.171). Он ищет только точные слова, поэтому результат слабый.
2. Потом взяла нейросеть intfloat/multilingual-e5-small (Recall@50 = 0.244). Она понимает смысл текста, поэтому нашла больше нужных объявлений.

## Проверка качества
Проверила, что в файле 2 колонки, нет лишнего индекса, и везде ровно по 50 item_id. Загрузила answer.csv на платформу, посмотрела метрику Recall@50.

## Ошибки и решения
1. Много одинаковых категорий (фильтр не помог) — искал по всем объявлениям сразу.
2. Модель считалась бы 3 часа на CPU — обрезала тексты до 128 символов, стало  примерно 30 минут.
3. В текстах были пропуски — заменяла их на пустые строки.
